# PhoNNeR

PhoNNeR — интерактивный каталог для глубокого поиска и сравнения смартфонов.

## Возможности

- поиск обычными фразами: «компактный Android до 80000 с eSIM»;
- фильтры по бренду, цене и возможностям;
- сортировка по оценке, цене и батарее;
- сравнение двух моделей с подсветкой лучших характеристик;
- адаптивный интерфейс и светлая/тёмная тема.

Сайт работает полностью в браузере и не требует сервера.
