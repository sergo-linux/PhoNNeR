# PhoNNeR

PhoNNeR — интерактивный каталог для глубокого поиска и сравнения смартфонов.

## Возможности

- федеративный каталог из 1 900+ телефонных записей до удаления дублей;
- три независимых внешних источника: Phone Specs API (276 подробных моделей), Smartdevices (1 247 записей) и STF Device DB (495 устройств), плюс локальная база PhoNNeR;
- нормализация и слияние моделей по бренду и названию: недостающие поля одной базы дополняются другой;
- поиск обычными фразами: «компактный Android с eSIM»;
- фильтры по бренду, цене и возможностям;
- сортировка по оценке, цене и батарее;
- сравнение двух моделей по 21 полю, включая происхождение данных;
- русский, английский, украинский и испанский языки;
- переработанная контрастная тёмная тема без вспышки светлого оформления, автоматический системный режим и ручное переключение;
- фирменный SVG favicon;
- адаптивный интерфейс и резервный каталог при недоступности внешней базы.

Сайт работает полностью в браузере и не требует сервера.

## Источники данных

- [Phone Specs API](https://github.com/rinehartwang1979/phone-specs-api) — подробные современные характеристики;
- [Smartdevices Pricing](https://github.com/sarangzambare/smartdevices_pricing) — архив из 1 247 телефонов и других умных устройств;
- [STF Device DB](https://github.com/DeviceFarmer/stf-device-db) — аппаратные идентификаторы и базовые характеристики;
- локальная подборка PhoNNeR — актуальные флагманы и ориентировочные цены.

Внешние базы загружаются параллельно. Ошибка одного источника не блокирует каталог и сравнение по остальным данным.
